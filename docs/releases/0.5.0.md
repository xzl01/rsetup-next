# rsetup-next 0.5.0

Rust 原生的一站式 SBC 控制中心，提供 CLI、TUI 和中英文 Web 界面，不再依赖旧版 rsetup 执行器。

## 本次更新

- **软件源测速**：在「管理 → 软件源」测试可信镜像，分别展示系统源和 Radxa 源的响应时间、索引采样速率与失败状态。可停止后续测试，选择结果后仍需预览并确认换源。
- **UEFI + DT Overlay**：Q6A / Q8B 共用原生 EFI/BLS 后端，支持受保护配置的授权读取、精确预览、备份与失败回滚。
- **GPIO 功能图**：结合保存的 Overlay 配置显示当前分配；未分配引脚显示准确默认功能，包含 Dragon Q8B 官方引脚数据。
- **硬件管理**：Overlay、摄像头单帧测试、温控策略与风扇曲线、LED / RGB 控制、受保护的 SPI 启动闪存操作。
- **系统维护**：软件源切换、系统更新、SSH / Docker 生命周期、电源策略、存储扩容、FAQ 与社区联系方式。

## 安装

提供 Debian 13 构建的 `amd64` / `arm64` 软件包，CI 在 Debian 12 上执行安装与运行冒烟测试。Dragon Q8B 使用 **arm64** 包。

```sh
sudo apt install ./rsetup-next_0.5.0-1_arm64.deb
rsetup-next --version
rsetup-next serve
```

Web 默认仅监听本机；默认变更策略是预演。需要实际修改时显式启用 `--live-execution`，并确认具体操作。

```sh
# 测试指定镜像，不修改软件源，也不需要 root
rsetup-next sources benchmark --mirror official --json
# 测试所有受支持的镜像
rsetup-next sources benchmark
```

测速由运行 rsetup-next 的 SBC 发起，不是浏览器所在电脑。每个镜像最多采样两个 512 KiB 索引，每个请求最多 6 秒；小样本结果不代表带宽上限或所有软件包的可用性。演示模式的测速数据明确标为模拟。

## 验证边界

- 发布包经过 Rust / 浏览器回归检查，以及 Debian 12 双架构安装和命令运行检查。
- Q8B 已进行只读实机探测；本次发布不代表所有 SBC 的 Overlay 激活、SPI 写入、风扇和引脚电气行为都完成实机验证。
- EFI Overlay 变更绑定预览中指定的内核启动项，不会自动修改默认启动项；需要启动对应内核才会生效。
- Debian 包包含 CLI、TUI、Web 与受控提权助手；可选 Tauri 桌面壳不在本次 `.deb` 附件中。
